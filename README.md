#  Customer Shopping Behaviour Analysis

Customer Shopping Behaviour Analysis is an end-to-end data analytics project that explores customer purchasing patterns using **Python, MySQL, and Power BI**. The project focuses on cleaning and transforming raw customer transaction data, performing exploratory data analysis (EDA), solving business problems with SQL, and building an interactive dashboard to generate actionable business insights.

---

#  Business Problem

Retail businesses generate large volumes of customer transaction data but often struggle to understand customer purchasing behavior and spending patterns. This project aims to analyze customer demographics, product preferences, subscription behavior, and revenue trends to help businesses improve marketing strategies, customer retention, and sales performance.

---

#  Data & Tools

**Dataset:** Customer Shopping Behavior Dataset

**Tools & Technologies:** Python, MySQL, Power BI

**Python Libraries:** Pandas, NumPy, Plotly

---

#  Major Results

* Cleaned and preprocessed customer shopping data by handling missing values and performing feature engineering.
* Created **Age Group** and **Purchase Frequency** features to improve customer segmentation.
* Compared customer spending based on gender, subscription status, and shipping methods.
* Identified the highest-rated and most frequently purchased products using SQL.
* Segmented customers into **New**, **Returning**, and **Loyal** groups based on purchase history.
* Built an interactive Power BI dashboard to monitor sales trends, customer demographics, and business KPIs.
* Generated business recommendations to improve customer retention and marketing effectiveness.

#  Project Description

##  Data Preparation

* Imported and explored the customer shopping dataset.
* Checked data quality and handled missing values.
* Standardized and renamed column names.
* Performed feature engineering by creating **Age Group** and **Purchase Frequency (Days)**.
* Prepared the cleaned dataset for SQL analysis and Power BI visualization.

---

##  Exploratory Data Analysis (EDA)

* Analyzed customer demographics and purchasing behavior.
* Compared spending across age groups and gender.
* Examined product category performance and seasonal trends.
* Analyzed payment methods, shipping types, discounts, and subscription status.
* Created interactive visualizations using Plotly to uncover customer insights.

---

##  SQL Business Analysis

Performed SQL analysis to answer key business questions:

* Revenue comparison between male and female customers.
* Customers who spent above average using discounts.
* Top-rated products based on customer reviews.
* Spending comparison by shipping type.
* Subscriber vs. non-subscriber revenue analysis.
* Customer segmentation using CTEs and CASE statements.
* Top purchased products within each category using Window Functions.
* Revenue contribution across different age groups.
